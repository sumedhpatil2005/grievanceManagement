# Grievance Management System

> A streamlined platform to log, track and resolve grievances efficiently (e.g., for students,for colleges).



## 🧠 About The Project

Grievance Management System is a full-stack application that allows users to submit grievances, track their status, and enables admins to manage and resolve them.

This repository contains:
- ❗ Grievance submission
- 📋 Status tracking
- 🔑 User authentication
- ⚙️ Admin dashboard
